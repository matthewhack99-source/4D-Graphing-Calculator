# 4D Graphing Calculator

A Python-based 4D graphing calculator built using Pygame.

## Features

- Visualise 4D mathematical functions.
- Rotate the graph in 3D and 4D.
- Change the Z-slice manually or animate it.
- Zoom in and out.
- Enter your own mathematical expressions.
- Built-in example functions.
- Colour-coded W-axis.

## Requirements

- Python 3.10+
- Pygame

## Installation

Install Pygame:

```bash
pip install pygame
```

## Running

```bash
python main.py
```

## Controls

| Key / Action | Function |
|---|---|
| Mouse drag | 3D rotation |
| Shift + drag | 4D rotation |
| Q / E / A / D | 4D rotation |
| Scroll wheel | Zoom |
| + / - | Zoom |
| Left / Right | Change Z-slice |
| Space | Toggle Z animation |
| Tab | Change preset |
| R | Reset |
| Click expression box | Edit formula |
| Enter | Apply formula |
